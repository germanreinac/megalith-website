# Art files

Put each kind of art in its folder. PNG with a transparent background for drawings,
`.glb` for 3D models. Rough versions are fine; they can be swapped later with the same file name.

| Folder | What goes in it |
| --- | --- |
| `water/` | Water areas from the comic, a layered water panel (PSD or Procreate), and, if possible, a square seamless top-down water tile (about 2048 px) split into black-and-white layers: dark shapes, light shapes, lines. Also the grain texture |
| `boat/` | The boat model as `.glb` (under about 20,000 triangles, plain colours or one texture, sail as a separate object, both sail versions) |
| `backdrop/` | The island city, 4 to 6 clouds, the sun with its face, each as its own PNG |
| `characters/` | Dji and Skit as flat cut-outs in 4 poses: standing, holding on, cheering, seasick |
| `items/` | Floating things to collect: fish, bottle, crate, star scroll |
| `rewards/` | Images shown when an item is collected: panels, sketches, behind the scenes |
| `brand/` | The Megalith logo, the lettering font, colour swatches |
